My Browser — Java + Android WebView پروجیکٹ

اس میں سرچ/ایڈریس بار، ویب سائٹس ایپ کے اندر کھولنا، بیک/فارورڈ، ہوم، ریفریش، بنیادی ٹیبز اور براؤزنگ ڈیٹا صاف کرنے کا آپشن ہے۔

اہم حدود:
- یہ Java/Gradle Android پروجیکٹ ہے، HTML-to-APK ZIP نہیں۔
- پروجیکٹ اس وقت compile یا فون پر test نہیں کیا گیا۔
- APK بنانے کے لیے Android SDK، Gradle اور Java Android project build کی سپورٹ والا پلیٹ فارم درکار ہے۔
- Private mode بنیادی ہے، مکمل incognito isolation یا anonymity کی ضمانت نہیں۔
- ڈاؤن لوڈ مینیجر اور pop-up window سے نئے ٹیب میں کھولنے کی مکمل سپورٹ ابھی شامل نہیں۔
